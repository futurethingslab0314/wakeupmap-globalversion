# WakeUpHere 到站語音

實作日期：2026-11-23。

真正鬧鐘與 Ctrl+H 模擬共用聲音順序：

1. 中文說「[國家]的[城市名]到了」。
2. 第一遍結束後停 3 秒，再完整說一次。
3. 第二遍結束後播放原有循環雷達鬧鈴。

語音、間隔或鈴聲期間，搖桿確認鍵都會停止聲音與延後播放工作。真正鬧鐘維持原有按鈕時間及醒來紀錄流程；Ctrl+H 不新增正式紀錄。

## 相容性與備援

使用瀏覽器 Web Speech 的中文聲音，優先 zh-TW，再採其他 zh 聲音，不增加 AI prompt 或後端 API。啟動時預先讀取聲音清單。若當下沒有可用中文聲音、API 不支援、播放錯誤，直接播原鬧鈴；語音未開始 3 秒或開始後 15 秒仍未完成，也會取消語音並改播鬧鈴。

此功能依賴該台 Chromium 可用的中文語音與音效設定。網站發布不會替 Pi 安裝系統聲音；若中文語音不可用，只會聽到備援鬧鈴，需另查該 Pi 的瀏覽器語音能力。軟體無法確認喇叭是否真的出聲，實機必須用 Ctrl+H 驗收。

## 驗收

- Ctrl+H：聽到兩遍正確國家／城市，第一遍完成後停 3 秒，再接原鈴聲。
- 第一遍、3 秒間隔、第二遍及原鈴聲各測一次按鍵停止，不再延後出聲。
- 無中文聲音、語音拒絕播放或卡住時，仍響原鬧鈴。
- 正式八點確認仍寫入原始按下時間；模擬不寫正式紀錄。
