# WakeUpHere 到站語音設計與實作計畫

使用者已確認：城市當地鬧鐘時間到，中文說「國家的城市到了」；第一句結束後停 3 秒，再說一次；第二句結束後開始原有循環鬧鈴。語音缺失／錯誤／逾時改用原鬧鈴。確認、取消與重置需清除語音及所有延後工作，維持原有醒來確認事件。

1. 以可注入語音與時鐘的控制器測試兩次播放、3 秒間隔、備援、停止與舊回呼失效。
2. 實作獨立 announcement.js，使用瀏覽器中文聲音，優先 zh-TW，其次其他 zh；無中文聲音直接備援。啟動逾時 3 秒、播放逾時 15 秒，避免無限等待。
3. 接入現有響鈴／停止／重置流程及模擬鬧鐘；模擬不寫正式紀錄。
4. 執行鬧鐘／確認相關測試、型別與建置，更新說明並只提交本次檔案到 GitHub。

不使用 AI prompt 或新後端服務。未實際驗證 Pi 的語音包；瀏覽器回報有語音不等於喇叭確實出聲。中文語音不可用時仍必須響鈴。
